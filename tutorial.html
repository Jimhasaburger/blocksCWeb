Keybinds

  • 1,2,3 | Tools
  • Del | delete
  • Ctrl+d | Will move ur camera, but it clones part
  • esc | close
  • f11 | fullscreen

Saving and loading

saving and loading is done via file > save/load, It uses a JSON format that i wont explain here

how to use it actually

basically, you can click on parts to select them, you have a gizmo, you can switch between

different tools (move rotate scale) using the keybinds or the topbar

the topbar contains other things too, the square thats colored is to recolor stuff. click on it to recolor.

you can hover over the topbar buttons to see their names.

file menu has a new button that clears scene

options lets you set snapping and outline settings

for more help you can ask me in the discord (at the header of this site)

latest version

run

you can "run" the creation by pressing the green > button (run button), click it again to stop.

it will copy your build to a backup, then run the EXPERIMENTAL physics. clicking it again reverts the backup

parts are anchored by default, unanchor them so physics work.

the default scene shows all the different part types and a simple physics thing

the default scene is mainly just for debug but i think its also good to show features.
